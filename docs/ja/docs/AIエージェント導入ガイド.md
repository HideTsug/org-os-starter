# AIエージェント導入ガイド（clone 前）

> 本文書は、**まだこのリポジトリを clone していない** AIエージェント向けに書かれている。典型的には、利用者から「自分の組織のAI知識基盤を作りたい」と相談されただけの状態のAIである。自己完結しており、raw URL 1本で読み込める:
>
> `https://raw.githubusercontent.com/HideTsug/org-os-starter/main/docs/ai-agent-guide.md`
>
> すでにこのリポジトリのチェックアウトの中にいる場合は、本ガイドではなく [`AGENTS.md`](../AGENTS.md) から始めること。本ガイドが扱うのは、利用者側にリポジトリが**存在する前**の分岐だけである。

いま見ているもの: Org-OS Starter は、組織がAIネイティブになるための知識基盤スターターキットで、**GitHub テンプレートリポジトリ**として配布されている。MIT ライセンスの無料 OSS であり、コンサルティング契約や導入支援サービスではない。全体像は [`README.md`](../../../README.md) にある。以下の4つの確認を順に行う。どれも、飛ばすと導入が失敗する既知の分岐である。

## 1. 対象を確認する

作業に入る前に、利用者と次を確定する:

- **どの組織の導入か。** 1リポジトリは1組織のためのもの。複数の組織が挙がったら、まず1つに絞る。
- **依頼者は導入DRIか、委任された実装者か。** 導入DRIはマージ権限を持ち規範の起案を主導する人。依頼者が委任者なら、DRIが存在し、この作業を把握していることを確認する — DRIは導入ガイド Step 0 で人間が決める3つのうちの1つで、AIが代わりに埋めることはできない。
- **最初の痛みは何か。** 導入ガイドは狭い最初のユースケースを1つ求める。「あれどうなってたっけ？」が最も多く発生する領域を利用者がすでに言えるなら、ここで控えておく。

## 2. 実行環境を自己判定する

このセッションの自分がどちらかを正直に判定する:

- **ファイルの作成・編集と `git` / `gh` の実行ができる**（Claude Code 等のエージェント型環境）。導入の全工程を運転できる。セクション3へ進む。
- **会話しかできない — ファイル書き込みもシェルも無い。** コピー＆ペーストで導入を即席実行しない。導入にはエージェント型AI環境が必要であることを利用者に伝え、そのエージェントに渡すための本ガイドの raw URL を案内し、利用者自身が読む入口として [`README.md`](../../../README.md) を示す。

あわせて、恒常的な制約を早めに明言する: v0.1 運用プロファイルの外部知識ソースは **Google Drive のみ**で、各利用者本人の OAuth 許可を通して読む。自分の環境が実際にその経路で Drive を読めるかは導入手順の中で検証する — 読めない場合に別のアクセス経路で代用してはならない。

## 3. private リポジトリ化の同意を取る

テンプレートは public で始まるが、充填後の複製には組織の規範・意思決定・実運用データが入る。何かを作る前に、次の2点への明示的な同意を利用者から得る:

- 組織の複製は、上流リポジトリの **「Use this template」** で作成する — public な上流を clone / fork してそこへ push するのではない。
- 複製は**作成した瞬間から private** にする。受入基準は機械的に確認できる: 新リポジトリ内で `gh repo view --json visibility` を実行し、`"visibility":"PRIVATE"` が返ること。`gh` が使えない、またはホストが GitHub でない場合は、ホスティングの設定画面で「Private」であることを人間が確認する。いずれの場合も、リポジトリができたら [`docs/governance/運用規約.md`](governance/運用規約.md) の検証記録セクションに確認を記録する。

どちらか一方でも未確認のまま先へ進まない。「あとで private にした」public 複製は、その履歴がすでに漏れている。

## 4. 導入ガイドへ引き渡す

private の複製ができて clone したら:

1. 新リポジトリの [`AGENTS.md`](../AGENTS.md) を開く — リポジトリ内のエージェント向け入口で、1回だけの任意の応援確認を含む導入の流れが書かれている。
2. [`docs/導入ガイド.md`](導入ガイド.md) の **Step 0** から始める: 人間が決めるのは導入DRI・承認体・狭い最初のユースケースの3つだけ。それ以外はAIが質問しながら埋めていく。
